DATA TYPE CONVERSIONS ( Type Conversion, Type Casting)
________________________________________________________________________________________________________
               ┌─────────────────────────────────────────┐
               │         DATA TYPE CONVERSIONS           │
               └────────────────────┬────────────────────┘
                                    │
         ┌──────────────────────────┴──────────────────────────┐
         │                                                     │
 ┌───────┴───────┐                                     ┌───────┴───────┐
 │ Type Conversion (Implicit)                          │ Type Casting (Explicit)       │
 ├─────────────────────────────────────────────────────┼───────────────────────────────┤
 │ • Handled automatically by compiler                 │ • Forced manually by coder    │
 │ • No data loss (Widening/Promotion)                 │ • Risk of data loss (Narrowing)│

   └────┬─────┘                                          └────┬─────┘

   ┌──────────┐                                          ┌──────────┐
   │   int    │                                          │  float   │
   └────┬─────┘                                          └────┬─────┘

   ┌──────────┐                                          ┌──────────┐
