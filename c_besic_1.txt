Break
________________________________________________________________________________________________________
    [A] Start Loop
         │
         ▼
 ┌──[B] Loop Condition Valid?
 │       │
 │       ├─► (Yes) ──► [C] Check Break Condition
 │       │                  │
 │       │                  ├─► (True)  ──► [D] Execute 'break' ──┐
 │       │                  │                                     │
 │       │                  └─► (False) ──► [E] Run Loop Body ┘   │
 │       │                                       │                │
 │       └◄──────────────────────────────────────┘                │
 │                                                                │
 └──────► (No / Broken) ──► [F] Loop Terminated ◄─────────────────┘
                             (Code Outside Loop)

Function declaration
________________________________________________________________________________________________________
    return_type function_name(parameter_type1, parameter_type2);

    [A] Start Program Compilation
         │
         ▼
    [B] Compiler reads Function Declaration ──► (Saves function signature/blueprint)
         │
         ▼
    [C] Execution starts at main()
         │
         ▼
    [D] Function Call encountered ───────────► (Compiler validates arguments against [B])
         │                                          │
         ▼                                          ▼
    [F] Return to main() <─────────── [E] Jump to Function Definition
         │                                 (Executes function body logic)
         ▼
    [G] End Program Execution
